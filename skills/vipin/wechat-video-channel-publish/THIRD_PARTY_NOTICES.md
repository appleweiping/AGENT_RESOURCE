# Where this code came from

## social-publish-skills (most of this folder)

This folder started as the WeChat Channels (Tencent) part of
[puppyfront-web/social-publish-skills](https://github.com/puppyfront-web/social-publish-skills),
copied at commit
[`c8a46f6`](https://github.com/puppyfront-web/social-publish-skills/commit/c8a46f6)
(2026-04-02) with the other platforms left out. That project is MIT-licensed
("Copyright (c) 2026 social-publish-skills contributors"), so this folder, my changes
included, is under the MIT license in [LICENSE](LICENSE) rather than the repository's
Apache-2.0.

Compared with that commit:

| File | Relation to social-publish-skills |
| --- | --- |
| `src/browser.ts`, `src/config.ts`, `src/paths.ts`, `src/progress.ts` | Unchanged |
| `src/platforms/tencent.ts` | Upstream's file with its header comment; 444 of its 466 lines are kept, and I added about 530 lines: the long description, cover upload and its dialogs, the confirmation dialogs after submitting, error diagnostics and debug screenshots, and the pinned comment |
| `src/cli.ts` | Upstream's CLI cut down to the `tencent` commands; about 90 of its 104 lines are upstream's |
| `src/stealth.min.js` | Upstream's copy plus two header lines; the file itself is generated by puppeteer-extra (see below) |
| `SKILL.md`, `references/publish-workflow.md`, `references/runtime-requirements.md` | Rewritten in English from the docs in upstream's `skills/tencent-upload/` |
| `package.json`, `tsconfig.json`, `.gitignore` | Adapted from upstream's |
| `scripts/tencent_*.ts`, `references/privacy-checklist.md`, `assets/`, `agents/` | Not from upstream |
