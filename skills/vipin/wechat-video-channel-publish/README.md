# wechat-video-channel-publish

A Playwright CLI, plus agent instructions in `SKILL.md`, that logs into WeChat Channels
(微信视频号) with a QR code and uploads, schedules or drafts a video with title, topics,
description and cover. I use it so an agent can publish my videos without me clicking
through the creator site.

Needs: Node.js 20+ and Playwright's Chromium.

## Example

```bash
npm install
npx playwright install chromium
npm run build

node dist/cli.js tencent login --account my_account     # scan the QR code once
node dist/cli.js tencent check --account my_account     # prints valid / invalid
node dist/cli.js tencent upload \
  --account my_account \
  --file /absolute/path/to/video.mp4 \
  --title "Title" \
  --tags "topic1,topic2" \
  --caption "Longer description" \
  --cover /absolute/path/to/cover.jpg \
  --schedule "2026-05-02 20:30"
```

`--draft` saves a draft instead of publishing, and `--pinned-comment` tries to post a
comment after publishing. Both are best effort: the creator site sometimes refuses to
save a draft, and then the CLI prints what the buttons and dialogs showed instead of
waiting forever. Do not combine `--draft` with `--schedule`; test drafts without a
schedule first.

Set `SOCIAL_PUBLISH_HEADLESS=0` to watch the browser, `SOCIAL_PUBLISH_CHROME_PATH` to use
an installed Chrome or Edge (better H.264 support), and `SOCIAL_PUBLISH_DATA_DIR` to move
the data folder.

## Privacy

Login cookies are saved to `~/.social-publish-skills/cookies/tencent/`, outside the repo.
Never commit cookie JSON, `.env` files, screenshots or debug logs; `.gitignore` already
excludes the usual ones, and `references/privacy-checklist.md` lists what to check
before pushing.
